What you can import

Built in
Zerodha Console holdings (.xlsx)
The Equity and Mutual Funds sheets. Stocks, ETFs, gold bonds and funds are recognised automatically. The Combined sheet is skipped so nothing is counted twice.
Built in
ICICI Bank FD summary (.xlsx)
Each deposit with its balance, accrued interest, rate and maturity date.
Built in
Mutual fund SOA summary (.xlsx)
Scheme name, invested value, market value, balance units and NAV date. Names get an “SOA ·” prefix, so these stay separate holdings even when you hold the same fund elsewhere. Funds are matched by name; if the sheet has a Folio column it is used as well and kept in the ISIN field.
Built in
HDFC Bank FD summary (.xlsx)
Each deposit with its principal, rate, start and maturity dates. Interest is then calculated for you every day.
Built in
SBI Mutual Fund account summary (.ods or .xlsx)
The statement of account: units, NAV and cost of investment for each scheme, matched by folio and ISIN.
Any sheet
Other spreadsheets (.xlsx, .xls, .ods or .csv)
Needs a header row with columns such as Name (or Symbol), ISIN, Quantity, Average Price, Price (or NAV), Current Value, Invested and Type. Type can be stock, ETF, mutual fund, fixed deposit or savings. Title lines above the header are fine. Without a Type column, ISINs starting INE are treated as stocks and INF as mutual funds.

You see a preview before anything is saved. Duplicates are rejected: importing again updates existing holdings (matched by folio, ISIN or FD number), skips rows that haven't changed, and holdings missing from the file are only removed if you tick them. The file itself is not stored.
